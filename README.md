# Flutter UI Assignment

## Description

This project contains a simple Flutter screen built using basic Flutter widgets.

## Requirements

* Scaffold
* AppBar
* Row as the main layout
* Container
* Text
* Icon

## AppBar Customization

The AppBar was customized using:

* `backgroundColor`
* `centerTitle`
* `elevation`
* `leading`
* `actions`

## Screen

The screen displays a simple profile section with an icon and text.

## Technologies

* Flutter
* Dart
